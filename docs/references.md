# References & Evidence Register

Every external claim the design relies on lives here with a status. **Code may only depend
on VERIFIED claims.** An UNVERIFIED claim may shape a plan, but the code path that relies
on it must quarantine on surprise and must get a fixture + test before it is trusted.

Status meanings:
- **VERIFIED**: checked against a real file in `tests/fixtures/` and pinned by a test.
  Scope is exactly what was tested (e.g. "one Q2 standalone filing"). Not a universal law.
- **OBSERVED**: seen in live data on a stated date, but not pinned by a committed fixture.
- **UNVERIFIED**: from documents, memory or another tool's assertion. Do not code against it.
- **CHOICE**: a methodology decision, not a fact. Changing it is a design change.

Last reviewed: 2026-11-13.

## 5. Known data limitations (affect results, must be disclosed in any backtest output)

- **L1 Survivorship bias**: `index_constituents_history` starts at the first snapshot date. `backfill-index` (architecture §11.6) reconstructs 2024-10-01 → first snapshot from the regular NSE Indices notices [IDX4-IDX7]. It needs local price history for the event dates, and dummy/spin-off days remain approximate until `TEMPORARY` rows are added. Any backtest with an as-of date before that uses today's constituents and is **survivorship-biased** until historical changes are backfilled manually.
- **L2 Restated comparatives**: after demergers or mergers, prior-year quarters are as-reported (pre-restatement) until restated values are captured from a later Reg. 34 annual XBRL (FY level only) or a verified PDF supplement. YoY growth across such events is flagged, not trusted.
- **L3 Half-yearly balance sheet and cash flow**: in Q1/Q3, balance-sheet and cash-flow inputs are carried forward from the last H1/FY filing; every derived ratio exposes `bs_as_of` / `cf_as_of`.
- **L4 Quarterly debt excludes leases** (X16) and **cash excludes non-current treasury investments** (X17) until annual notes are parsed.

## 6. Methodology choices (CHOICE)

| # | Choice |
|---|---|
| C1 | Money is `DECIMAL(20,2)` rupees in DuckDB/Parquet and `decimal.Decimal` in Python. Never float. |
| C2 | Price series adjusted only for splits, bonuses, rights bonus element and demergers. No dividend adjustment; dividends go to a separate total-return series. |
| C3 | Demerger price factor = parent's ex-date open / prior close. |
| C4 | Unconditional gap auditor threshold: \|Open_t / Close_{t−1} − 1\| > 10%. |
| C5 | Effective tax rate fallback for loss-makers = 0 (no synthetic tax shield). Statutory 25.17% (Sec. 115BAA) is used only where a ratio explicitly needs a statutory rate. |
| C6 | Gross profit is computed only for `INDAS_CORP` with (materials + stock-in-trade purchases) ≥ 10% of revenue; otherwise NULL. |
| C7 | Universe v1: NSE Mainboard `EQ`/`BE`/`BZ`, starting with Nifty 500. SME (`SM`/`ST`) excluded. |
| C9 | **v1 data scope**: market data, corporate actions and index snapshots from `2024-10-01`; financial statements and shareholding with period end `>= 2025-03-31` (Q4 FY25, first Integrated Filing quarter [X38]; moved from 2024-12-31 on 2026-11-13 because Dec-2024 results are legacy format). Older inputs are vaulted but not parsed; no legacy-format parsers. As of Nov 2026: 7 quarters (Q4 FY25–Q2 FY27), so TTM is available and YoY TTM unlocks with Q3 FY27 results; 3Y/5Y windows are NULL. | Owner decisions 2026-11-13 |
| C8 | Personal, single-user research. No redistribution. Polite, rate-limited fetching with on-disk caching. This is not legal compliance with exchange terms, which prohibit automated access. |
| C10 | **PE earnings = trailing-12-month owners' profit from continuing operations**: per filing, `COALESCE(owners, total) − ProfitLossFromDiscontinuedOperationsAfterTax`, then summed over 4 quarters. Excludes Ind AS 105 / demerger-scheme gains (TMPV Q2 FY26: +76,170 → −6,446 Cr) [X52]. The NCI share of discontinued profit is assumed 0, because the XBRL does not split it; the error is at most that share. Exceptional items inside continuing operations are **not** stripped. ROE keeps owners' total profit. Decided 2026-11-13. |
| C11 | **Uniform canonical rules over Screener's per-company layout** (decided 2026-11-13): share of associates/JVs stays out of Other Income and PBT (`ASSOCIATES_PLACEMENT` divergence), and bank PBT stays after exceptional items, so PBT − Tax = Net Profit ties (`BANK_EXCEPTIONAL`). The ~70 golden values stay in `tests/test_screener_parity.py`. |
| C12 | **Bitemporal visibility of restated / pre-listing history**: every fact a filing carries, including comparatives and derived quarters, becomes visible at that filing's broadcast (or board-meeting fallback), never earlier (`promoter.py`, per filing). A demerged entity's history before its first own filing does not exist for PIT reads. Tata Motors Ltd (CV): first filing Q2 FY26, 13-Nov-2025 19:04:53 IST; Screener's Sep-2024–Jun-2025 quarters have no XBRL source here. |
| C13 | **Lender classification** (INDAS_NBFC): lending iff `Loans / Assets >= 10%` when the filing has a balance sheet, else `InterestEarned / RevenueFromOperations >= 25%`. Lowest among the 10 Batch 4 lenders: 70% / 84%; Jindal Poly Investment: 0% / 0.2%. A rule on `InterestEarned == 0` alone would have misclassified Jindal Poly (interest 0.06 Cr). Non-lenders are **flagged** (`is_lending_nbfc = FALSE`, lending ratios NULL), not quarantined: their statements are valid. |
| C14 | **Continuing ROE and core profit**: `roe_continuing = TTM continuing owners' profit / owners' equity`, with **the same denominator as headline `roe`** (latest balance sheet), so the two differ only in the numerator. Headline ROE still uses the latest, not average, equity (known gap, architecture §15); switching both to average is one change, deferred to keep ROE comparable. `core_profit_ttm = continuing owners' profit − TTM exceptional items × (1 − TTM effective tax rate)`: the filing does not tag tax on exceptional items, so the ETR is an approximation. Headline PE keeps exceptional items (C10). Lender averages (credit cost, NIM proxy, RoA) use (opening + closing) / 2 over 12 months and are NULL without the opening balance sheet. |
| C15 | **Effective EPS**: `COALESCE(NULLIF(filed, 0), owners' profit / period-end shares)`, also for continuing EPS; filed values stay as sub-rows. `screener_features.eps_ttm` is always derived (TTM owners' profit / current shares), consistent with `pe`. |
| C16 | **ROE on closing equity, efficiency ratios on averages** (decided 2026-11-13): `roe` and `roe_continuing` divide TTM profit by the **latest closing** owners' equity, matching Screener's TTM ROE and available from the first balance sheet. `roa`, `nim_asset_proxy`, `credit_cost` use (opening + closing) / 2 over 12 months and are NULL without the opening balance sheet. `roic` = TTM NOPAT / (opening + closing) / 2 invested capital, NULL without the opening balance sheet; `croic` uses the same average (aligned 2026-11-13). Banks: `cost_to_income = OperatingExpenses / (NII + OtherIncome)`; `loans` / `loans_as_of` / `loans_avg_from` hold **advances** for banks. |
| C17 | **Schema upgrades are additive and idempotent**: `init-db` (`apply_schema`) adds any nullable, constraint-free column that `schema.sql` declares but the database lacks (`ALTER TABLE … ADD COLUMN IF NOT EXISTS`); a constrained new column raises `SchemaMigrationError`. New columns are appended before the `PRIMARY KEY` line so the positional copy `screener_features_history → screener_features` stays aligned. |
| C18 | **Per-company default scope** (Mandate 3, decided 2026-11-13): `default_quarterly_scope` = CONSOLIDATED when the company's latest quarterly filing visible at as-of has a consolidated version, else STANDALONE; `default_annual_scope` the same on 12-month filings (falls back to the quarterly default). This is Screener's convention (S1, S19). A TTM window uses **one scope for all four quarters**: the default if complete, else the other scope only if *it* is complete (`FALLBACK_DEFAULT_INCOMPLETE`), else an H1/FY bridge (`YTD_BRIDGE`), else balance-sheet-only ratios (`BALANCE_SHEET_ONLY`); standalone and consolidated quarters are never mixed. A manual override (`scope-override`, audited in `company_overrides`) pins the scope and is never silently replaced. Exposed as `scope_used`, `scope_reason`, `default_quarterly_scope`, `default_annual_scope`. The anchor is `pat` (every profile files it): the previous chooser anchored on `revenue_from_operations`, which banks and insurers do not file, so they never got a TTM window. |
| C19 | **Cash-conversion and operating-leverage ratios** (industrial books only; NULL for lenders and insurers): `sloan_accrual = (TTM PAT − CFO − CFI) / avg total assets` (cash-flow accrual, Sloan 1996 / Richardson et al. 2005 form); `cfo_to_ebitda` (EBITDA > 0); `fcf_to_pat` (PAT > 0); `working_capital_intensity = (current trade receivables + inventories − current trade payables) / TTM revenue`; `net_debt_to_fcf` (FCF > 0); `cost_of_debt = TTM finance costs / avg (borrowings + labelled leases)`; `gross_ebitda_spread = (gross profit − EBITDA) / revenue`, only where gross profit exists (COGS ≥ 10% of revenue, C6); `dol = EBIT YoY / revenue YoY` only if \|revenue YoY\| ≥ 5% and both EBITs positive; `receivables_sales_divergence = receivables YoY − revenue YoY`. The last two need 8 in-scope quarters (C9) and are NULL until Q3 FY27 data. `fcff_yield` already adds back operating-classified interest only, per filing (`interest_paid_cfo_class`), so FCFF is correct whichever way a filer classifies interest paid. `other_income_to_pbt` existed. |
